# Podcast — живой аудио-подкаст с текстовым чатом

**Podcast** — клиент-серверное приложение для проведения живых аудио-подкастов.
До двух спикеров могут общаться голосом через микрофон, а до шести слушателей —
слушать разговор в реальном времени. Все участники могут общаться в текстовом чате.

- **Голос** передаётся по **UDP** — минимальная задержка, как в живом разговоре
- **Чат и служебные команды** — по **TCP** — надёжная доставка текста

---

## ✨ Функции

### Спикер (максимум 2)
- Живая голосовая трансляция через микрофон
- Выбор устройства записи (микрофона)
- Кнопка включения/выключения микрофона
- Индикатор уровня громкости микрофона в реальном времени
- Слышит второго спикера (себя не слышит — без эха)
- Индикатор «кто сейчас говорит» (зелёная рамка у имени)
- Текстовый чат и список участников

### Слушатель (максимум 6)
- Прослушивание спикеров в реальном времени
- Регулятор громкости звука
- Индикатор «кто сейчас говорит»
- Возможность задавать вопросы спикерам в текстовом чате
- Список участников

### Общее
- Окно входа: имя, адрес сервера, выбор роли
- Уведомления о подключении и отключении участников
- История чата (последние 15 сообщений) для новых участников
- Ограничения ролей: не более 2 спикеров и 6 слушателей
- Единая тёмная тема интерфейса

## Требования

### Готовые релизы (вкладка Releases)
- **Windows:** устанавливать ничего не нужно — все библиотеки Qt уже включены в архив.
- **Linux:** библиотеки Qt также упакованы в архив.

### Сборка из исходников
- **Qt 6.4 и выше** (разработано и протестировано на Qt 6.7), модули: `Widgets`, `Network`, `Multimedia`
- CMake 3.16+
- Компилятор C++17 (MSVC, MinGW или GCC)

---

## Запуск готовой сборки

### Windows
1. Скачать и распаковать `Podcast-win-x64.zip`
2. Запустить сервер — файл `PodcastServer.exe`
3. Запустить клиент — файл `PodcastClient.exe`
4. Заполнить окно входа: имя, адрес сервера, роль

### Linux
1. Скачать и распаковать архив:
2. Запустить сервер:
   ```bash
   ./run_server.sh
   ```
3. Во втором терминале запустить клиент:
   ```bash
   ./run_client.sh
   ```
4. Заполнить окно входа: имя, адрес сервера, роль

> 💡 Если сервер и клиент на разных компьютерах — укажите в окне входа
> IP-адрес компьютера с сервером вместо `127.0.0.1`.

---

## Сборка из исходников

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
```

На выходе получаются два исполняемых файла: `PodcastClient` и `PodcastServer`.
